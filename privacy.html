Privacy Policy

Last updated: October 24, 2026

Purpose

MMA Manager Backup is a private integration using rclone to back up and restore the project owner's authorized files in Google Drive.

Google Drive Access

The integration accesses Google Drive only after the account owner authorizes it. Access is used for backup storage, file listing, integrity verification and recovery.

Data Storage and Security

Backup files are stored in the owner's Google Drive account. OAuth credentials and authorization tokens are intended to be stored securely outside this website. This website does not collect credentials or process backup files.

Data Sharing

The integration is intended for personal use. Google user data is not sold or used for advertising. No independent third-party sharing is intended.

Retention and Deletion

Backup retention and deletion are controlled by the account owner. Google account access can be revoked through Google Account settings.

Contact

For privacy questions, contact the project owner using the support email displayed on the Google OAuth consent screen.
